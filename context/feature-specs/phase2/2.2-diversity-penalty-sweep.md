# 2.2 — Diversity-Penalty Sweep

**Modules:** `experiments/probe_utils.py` (shared probe helpers), `experiments/diversity_penalty_sweep.py`
**Depends on:** 2.1 (`checkpoints/sl_adapter/`), 1.2 (`build_sl_prompt`), 0.2 (`HuggingFaceLLM`),
0.3 (`build_pole_schema_repr`), 0.4 (`load_benchmark`)
**Consumed by:** 2.3 (reuses `probe_utils`); 3.1 (uses the locked `diversity_penalty`).

---

## Objective

Choose the `diversity_penalty` for the Schema Linker's diverse beam search by **maximising the
entropy→ambiguity signal** on the POLE benchmark, with coverage and hallucination as guardrails.
Run k=5 diverse beam search at penalties **[0.2, 0.5, 1.0]**, score each, and lock the best.

This is a **standalone, lightweight probe** built directly on `HuggingFaceLLM.generate` (0.2) —
it does **not** use the full 3.1 inference/postprocessing stack (which doesn't exist yet). It
reproduces just enough beam handling to measure the signal, mirroring the original cached-beams
probe.

Output: `results/diversity_penalty_sweep.json` (the table below) and the chosen value written
to `config/schema_linker_inference.yaml` (`diversity_penalty: <chosen>`), which 3.1 reads.

## Shared probe helpers — `experiments/probe_utils.py`

```python
# experiments/probe_utils.py
"""Lightweight beam + entropy helpers for the diversity sweep (2.2) and probe re-run (2.3)."""
from __future__ import annotations

import math
from collections import Counter

from pipeline.llm import GenerationConfig, HuggingFaceLLM
from pipeline.schema_linker.prompts import build_sl_prompt


def generate_beams(llm: HuggingFaceLLM, question: str, schema_block: str,
                   k: int, diversity_penalty: float) -> list[str]:
    """k diverse-beam pattern strings for one question (ordered by score desc)."""
    cfg = GenerationConfig(
        max_new_tokens=128, do_sample=False,
        num_beams=k, num_beam_groups=k, diversity_penalty=diversity_penalty,
        num_return_sequences=k,
    )
    return [c.text.strip() for c in llm.generate(build_sl_prompt(question, schema_block), cfg)]


def normalised_entropy(beams: list[str]) -> float:
    """Shannon entropy over the distribution of DISTINCT beam patterns, normalised to [0,1].

    Counts identical pattern strings as the same outcome; H_norm = H / log(k). Low when beams
    collapse to one pattern (confident/unambiguous), high when spread (ambiguous).
    """
    counts = Counter(beams)
    total = sum(counts.values())
    probs = [c / total for c in counts.values()]
    h = -sum(p * math.log(p) for p in probs if p > 0)
    return h / math.log(len(beams)) if len(beams) > 1 else 0.0
```

## Sweep — `experiments/diversity_penalty_sweep.py`

```python
# experiments/diversity_penalty_sweep.py
"""Sweep diversity_penalty ∈ {0.2, 0.5, 1.0}; pick the value with best entropy AUC under guardrails."""
```

Algorithm:
1. Load benchmark (125 items) and `build_pole_schema_repr()`; render the POLE schema block once
   via `to_prompt_string(include_properties=True)`.
2. Load the SL adapter: `HuggingFaceLLM(base, peft_adapter_path="checkpoints/sl_adapter")`.
3. For each `penalty ∈ [0.2, 0.5, 1.0]`:
   - For each item: `beams = generate_beams(...)`; record `normalised_entropy(beams)`,
     `covered(beams, gold_patterns)`, `hallucinated(beams, POLE labels/rels)`.
   - Compute **entropy AUC** = `roc_auc(entropies, [item.is_ambiguous])`, **Cov@5** = mean
     covered, **hallucination rate** = mean hallucinated.
4. **Selection:** among penalties with `Cov@5 ≥ 0.85` and the lowest hallucination, choose the
   one with the **highest entropy AUC**. If none clears the Cov@5 guardrail, report that and pick
   the best Cov@5/AUC trade-off, noting it in `decisions-log.md`.
5. Write `results/diversity_penalty_sweep.json` and the chosen value to
   `config/schema_linker_inference.yaml`.

## Edge cases

- At low penalty, unambiguous questions should collapse beams (low entropy) while ambiguous
  ones stay diverse — that separation is exactly what AUC measures. At high penalty, beams may
  hallucinate out-of-schema elements (hallucination guardrail catches this).
- Cov@5 here uses the standalone normalised comparison, not the full 3.1 alignment — it is a
  guardrail estimate, not the final intrinsic metric (that's computed post-3.1).
- POLE label/relationship sets for `hallucinated` come from `build_pole_schema_repr()`
  (node_labels and relationship_paths[*]["type"]).

---

## Acceptance criteria

Now (no GPU):
1. `normalised_entropy(["A","A","A","A","A"])` ≈ 0.0; `normalised_entropy(["A","B","C","D","E"])`
   ≈ 1.0; a 3/2 split is strictly between.
2. `roc_auc` returns 1.0 for perfectly separated scores, 0.5 for random/constant; `covered`
   and `hallucinated` pass small hand-built cases.

Deferred (GPU run):
3. The sweep runs over all 125 items at the three penalties, writes the json + table, and writes
   a single chosen `diversity_penalty` into `config/schema_linker_inference.yaml`.

## Handoff

`config/schema_linker_inference.yaml` now carries the locked `diversity_penalty` that 3.1's
`GenerationConfig` uses. `experiments/probe_utils.py` is reused by 2.3. The recorded AUC at the
chosen penalty is the figure 2.3 must improve on (vs the ≈0.62 general-model baseline).
