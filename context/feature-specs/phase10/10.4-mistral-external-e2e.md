## Objective

Run the three-condition evaluation with the **fine-tuned 7B Mistral** against the external
POLE benchmark, so the write-up has a fine-tuned-local column beside the 9.3 instruct-API
(Claude) column on a graph the student did not author — the whole point of "cleaning up the
gap." Gated cheapest-first (7.5 style) so a broken adapter is caught in minutes, not after a
~3h 300-query run.

## SL decoding — lock the diversity_penalty first

A local model's SL uses diverse beam search with a `diversity_penalty` from
`config/schema_linker_inference.yaml` (`_resolve_sl_decoding`, local branch). There is no
external-schema entry yet. Resolve in the gate chain:

- **G2a (sweep):** run `kaya/78_sweep_v3.slurm`-style sweep with `--dataset_version
  pole_external --results_tag pole_external` to lock `decoding[mistral7b]` for this schema (or,
  if the sweep is skipped for budget, **reuse the v3-locked `diversity_penalty: 1.0` and say so
  explicitly** — a documented pragmatic default, exactly as 9.3 reused the Phase-8 claude
  temperature).

## Gates (7.5 methodology, do not skip past a failure)

- **G0** — offline suite green + `validate_benchmark.py --profile pole_external` green on the
  10.1 graph.
- **G1** — full 100-item Cov@5 / EM@1 with `sl_adapter_pole_external` (`kaya/g1_*` harness).
  Proceed if Cov@5 ≥ 0.60; below → iterate 10.2/10.3, record the loop.
- **G2** — sweep (above) + entropy probe (`--dataset_version pole_external`).
- **G3** — AD probe (stratified external sample), base-Mistral AD; note detection counts.
- **G4** — full `run_evaluation config/pipeline_pole_external_mistral.yaml` (100×3) →
  `results/tables_mistral7b_pole_external_mistral.md` +
  `metrics_mistral7b_pole_external_mistral.json` +
  `qual_records_...`, then `analyze_qualitative.py` on the qual records.

## Acceptance criteria

1. Each gate's headline numbers + job IDs recorded in the tracker row (7.5 provenance style);
   no gate skipped past a failure; any G1 iteration documented.
2. G4 completes 100×3 with 0 tracebacks; the four external-Mistral artefacts written under the
   `pole_external_mistral` tag.
3. `analyze_qualitative.py` produces the qualitative report with non-empty per-type buckets.
4. Results reported **beside 9.3's claude-sonnet external numbers** (per-type EA, Detection
   F1, DSR) in the scorecard so the fine-tuned-local-vs-instruct-API comparison on a
   non-self-authored graph is legible. v2/v3 and 9.3's claude artefacts untouched.
