# 5.4 — Evaluation Harness

**Modules:** `experiments/run_evaluation.py`, `config/pipeline.yaml`
**Depends on:** 0.3 (`build_pole_schema_repr`), 0.4 (`load_benchmark`), 4.2 (`compute_metrics`,
`format_metric_tables`), 5.2 (`Orchestrator`), 5.3 (the three builders). **Requires a live Neo4j.**
**Consumed by:** the researcher (the run-the-experiment entry point).

---

## Objective

Run the orchestrator over all 125 benchmark questions for each of the three conditions, collect
`EvaluationResult`s (and Condition 3's `ad_predictions`), compute per-condition metrics, and render
Tables 1–3. Config-driven so the base model, adapters, Neo4j connection, and AD/Dis backends are
all set in `config/pipeline.yaml`, not code.

> **Fix (Pass-5 bug):** the Pass-5 harness referenced an undefined `c3_states` to gather
> `ad_predictions`. Here `run_condition` **returns** `(results, ad_predictions)` — the predictions
> are accumulated from each `PipelineState.ad_predictions` during the run — so detection metrics
> have a real source. Benchmark loading uses `load_benchmark` (0.4), not raw `json` + `BenchmarkItem`.

## `config/pipeline.yaml`

```yaml
neo4j:
  uri: "bolt://localhost:7687"
  user: "neo4j"
  # password via env var NEO4J_PASSWORD (do not commit real credentials)
  database: "neo4j"

models_registry: "config/models.yaml"       # the per-base registry from 2.1
active_model: "mistral7b"                    # which model_key to evaluate (must be in the registry)
# base + adapter paths are DERIVED from active_model:
#   base       = registry[active_model].base
#   sl_adapter = checkpoints/{active_model}/sl_adapter
#   qg_adapter = checkpoints/{active_model}/qg_adapter

ad:  {backend: "huggingface", model_name_or_path: "mistralai/Mistral-7B-v0.1"}   # swappable; defaults to active base
dis: null                                    # null → share the AD backend

benchmark: "data/benchmark-updated.json"
schema_linker_inference: "config/schema_linker_inference.yaml"   # holds locked diversity_penalty (2.2)
use_embedding_model: true                    # load sentence-transformers for the evaluator fallback
results_dir: "results/"
```

> **Running a different base** is a one-line change: set `active_model` to another key in
> `config/models.yaml` (e.g. `llama31-8b`) and re-run — the harness derives that base and its
> `checkpoints/{key}/{sl,qg}_adapter` paths. Run once per base for a base-model comparison; nothing
> else changes. If `ad` is omitted, it defaults to the active model's base.

> Credentials: read the Neo4j password from `NEO4J_PASSWORD` (or a local untracked secrets file).
> Never hardcode real credentials in the committed config.

## `experiments/run_evaluation.py`

```python
# experiments/run_evaluation.py
"""Run all three conditions over the benchmark; compute metrics; render Tables 1–3."""
from __future__ import annotations

import os
from pathlib import Path

import yaml

from experiments.build_condition1 import build_condition1
from experiments.build_condition2 import build_condition2
from experiments.build_condition3 import build_condition3
from pipeline.data.benchmark_loader import load_benchmark
from pipeline.evaluation.metrics import compute_metrics, format_metric_tables
from pipeline.orchestrator import Orchestrator
from pipeline.schema import build_pole_schema_repr
from pipeline.types import BenchmarkItem, Condition, EvaluationResult


def run_condition(benchmark: list[BenchmarkItem], components, condition: Condition):
    """Orchestrate every item for one condition.
    Returns (results, ad_predictions). is_failed / no-evaluation states map to an
    invalid_query EvaluationResult so all 125 questions appear in results.
    """
    orch = Orchestrator()
    results: list[EvaluationResult] = []
    ad_predictions: list[tuple[str, bool]] = []
    for item in benchmark:
        state = orch.run(item.question, item, condition, components)
        ad_predictions.extend(state.ad_predictions)        # empty for C1/C2
        if state.evaluation_result is not None:
            results.append(state.evaluation_result)
        else:
            results.append(EvaluationResult(
                question_id=item.question_id, condition=condition,
                is_correct=False, matches_any_interpretation=False,
                ambiguity_type=item.ambiguity_type, failure_mode="invalid_query",
                generated_cypher=state.generated_cypher or "",
                cyver_result=state.validation_result, retry_count=state.retry_count,
                is_first_attempt=True))
    return results, ad_predictions


def main(config_path: str = "config/pipeline.yaml") -> None:
    cfg = yaml.safe_load(Path(config_path).read_text())
    neo4j_uri = cfg["neo4j"]["uri"]
    neo4j_auth = (cfg["neo4j"]["user"], os.environ["NEO4J_PASSWORD"])
    database = cfg["neo4j"].get("database")

    # Resolve the active base + adapter paths from the model registry (2.1)
    registry = yaml.safe_load(Path(cfg["models_registry"]).read_text())
    key = cfg["active_model"]
    if key not in registry:
        raise SystemExit(f"active_model '{key}' not in registry. Known: {list(registry)}")
    base = registry[key]["base"]
    sl_adapter = f"checkpoints/{key}/sl_adapter"
    qg_adapter = f"checkpoints/{key}/qg_adapter"
    ad_spec = cfg.get("ad") or {"backend": "huggingface", "model_name_or_path": base}
    dis_spec = cfg.get("dis")

    schema = build_pole_schema_repr()
    benchmark = load_benchmark(cfg["benchmark"])

    # locked diversity_penalty from 2.2 (fail loudly if missing — don't silently default)
    sli = yaml.safe_load(Path(cfg["schema_linker_inference"]).read_text())
    diversity_penalty = sli["diversity_penalty"]

    embedding_model = None
    if cfg.get("use_embedding_model"):
        from sentence_transformers import SentenceTransformer
        embedding_model = SentenceTransformer("all-MiniLM-L6-v2")

    bundles = {}

    with build_condition1(neo4j_uri=neo4j_uri, neo4j_auth=neo4j_auth, database_name=database,
                          base_model_spec={"backend": "huggingface", "model_name_or_path": base},
                          schema=schema) as c1:
        c1.embedding_model = embedding_model
        results, _ = run_condition(benchmark, c1, "baseline")
        bundles["baseline"] = compute_metrics(results, ad_predictions=None)

    with build_condition2(neo4j_uri=neo4j_uri, neo4j_auth=neo4j_auth, database_name=database,
                          base_model=base, sl_adapter=sl_adapter, qg_adapter=qg_adapter,
                          schema=schema) as c2:
        c2.embedding_model = embedding_model
        results, _ = run_condition(benchmark, c2, "schema_grounded")
        bundles["schema_grounded"] = compute_metrics(results, ad_predictions=None)

    with build_condition3(neo4j_uri=neo4j_uri, neo4j_auth=neo4j_auth, database_name=database,
                          base_model=base, sl_adapter=sl_adapter, qg_adapter=qg_adapter,
                          schema=schema, diversity_penalty=diversity_penalty,
                          ad_spec=ad_spec, dis_spec=dis_spec,
                          embedding_model=embedding_model) as c3:
        results, ad_preds = run_condition(benchmark, c3, "disambiguation_enhanced")
        bundles["disambiguation_enhanced"] = compute_metrics(results, ad_predictions=ad_preds)

    print(format_metric_tables(bundles))
    # also persist results/bundles to cfg["results_dir"] for the thesis write-up
```

> `embedding_model` is set on C1/C2 after build (their builders don't take it); C3's builder accepts
> it directly. Alternatively, add `embedding_model` to all three builder signatures — minor, record
> in `decisions-log.md` if changed.

## Edge cases

- **`NEO4J_PASSWORD` unset** → `KeyError` with a clear cause; the harness deliberately does not
  embed credentials.
- **`active_model` not in the registry** → `SystemExit` listing known keys (don't run against an
  undefined base).
- **Adapters for the active model not yet trained** (`checkpoints/{active_model}/...` missing) → the
  HF load fails with a clear path; train 2.1/2.4 for that `model_key` first.
- **Missing `diversity_penalty`** in `schema_linker_inference.yaml` → `KeyError` (run 2.2 first);
  do not silently default — the locked value is a real experimental parameter.
- **`ad_predictions` for C1/C2** are empty (AD never runs) → `compute_metrics(..., None)` → DSR /
  detection render `—`. Only C3 passes real predictions.
- **Base-model comparison:** to evaluate a second base, set `active_model` to its key and re-run;
  results for each base are produced by a separate invocation (one base per run).
- **Sequential conditions** via `with` blocks free each condition's driver (and allow models to be
  GC'd) before the next — important on a single GPU.
- **All 125 questions appear** in every condition's results (failed runs → `invalid_query`), so the
  metric denominators are consistent across conditions.

## Acceptance criteria

Now (no GPU/DB; monkeypatch the builders to yield fake context-managed components, stub
`Orchestrator.run` to return canned `PipelineState`s, stub `compute_metrics`/`format_metric_tables`):
1. `run_condition` over a small benchmark returns one `EvaluationResult` per item; a state with
   `evaluation_result=None` becomes an `invalid_query` result; `ad_predictions` is the concatenation
   of each state's `ad_predictions`.
2. `main` resolves `base`/`sl_adapter`/`qg_adapter` from `config/models.yaml` via `active_model`
   (`base == registry[active_model].base`, adapters `checkpoints/{active_model}/...`), calls the
   three builders with those args, passes the locked `diversity_penalty` to C3, and passes
   `ad_predictions=None` for C1/C2 and the real list for C3.
3. An unknown `active_model`, a missing `NEO4J_PASSWORD`, or a missing `diversity_penalty` raises
   (no silent default).

Deferred (live system, GPU): full run over 125 questions × 3 conditions producing populated Tables
1–3.
