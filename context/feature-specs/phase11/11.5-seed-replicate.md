# 11.5 — Seed Replicate for Variance (OPTIONAL — drop without penalty)

**Modules:** one train YAML pair `config/{schema_linker,query_generator}_train_qwen_v3_seed2.yaml`
(a copy of 10.6's with a different `seed`, writing `{sl,qg}_adapter_v3_seed2`), and a re-run of
`kaya/104_g1_coverage_qwen.slurm` against them. **No pipeline code.**
**Depends on:** 10.6 (the 32B generic adapter to continue from) and 11.3 only if run at 72B.
**GPU: `--partition=rrifcs --gres=gpu:h100:1`.**
**Consumed by:** the writeup's error bars. Nothing depends on this step.

---

## Objective

Put a number on run-to-run variance so the phase's small-n movements can be called noise **with
evidence**. Every column so far is n=1: 10.4 wrote "small-n movements on schema (C3 15→10) and
temporal (C3 20→10) are 1–2 questions on n=20 cells, at noise level" — true, but asserted.
Repeating **one** continue-SFT at a second seed and re-running the intrinsic Cov@5 gives a
measured spread for the cheapest possible outlay.

**Scope discipline:** one adapter pair, one substrate (v3), intrinsic Cov@5 only — **not** a
second e2e. At 32B this is ~3 h/adapter on an idle card; at 72B ~7 h. Run it at whichever scale
has spare capacity; 32B is the better buy (cheaper, and the 32B column is the one with the most
cells already reported).

Everything except `seed` is held fixed, including the data files and every hyperparameter in
11.3's parity list. Write to `_seed2` paths so the headline adapters are untouchable.

---

## Acceptance criteria

1. One continue-SFT pair completes at a second seed; `eval_loss` curve recorded beside the
   original run's.
2. Intrinsic Cov@5 measured on the same substrate at the same locked `diversity_penalty`;
   the delta from the seed-1 run reported per type as well as overall.
3. Headline adapters and all `results/` artefacts byte-unchanged.
4. The writeup's "at noise level" claims are restated with the measured spread, or withdrawn.

## Handoff

None — this is a terminal step. If it is not run, say so explicitly in the tracker row rather
than leaving it `not started` and ambiguous, and keep the n=1 caveat in the writeup.
