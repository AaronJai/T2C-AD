# 5.1 — PipelineComponents

**Module:** `pipeline/components.py`
**Depends on:** 0.1 (`SchemaRepr`), 0.2 (`BaseLLM`), 3.1 (`SchemaLinker`), 3.2 (`EntityCache`),
3.6 (`QueryGenerator`). Constructs CyVer validators (CyVer library) and opens the Neo4j driver.
**Requires a live Neo4j** (cache load + validator construction query the graph).
**Consumed by:** 5.2 (orchestrator reads everything off it), 5.3 (condition builders construct it),
3.7 (`cyver_validator` reads the validators + `database_name`).

---

## Objective

Bundle every dependency one condition needs into a single injected container, built once per
condition. Holds the **constructed stage objects** (not raw LLMs) so the orchestrator just calls
them, plus the shared resources (driver, CyVer validators built once, entity cache loaded once,
schema, embedding model).

> **Reconciliation (supersedes the Pass-3 sketch).** The Pass-3 `PipelineComponents` held raw
> `sl_llm`/`qg_llm` and the orchestrator called functional stages. Phase 3 made the Schema Linker
> and Query Generator **classes** and Entity Lookup take a **cache**. So this container holds
> `schema_linker: SchemaLinker`, `query_generator: QueryGenerator`, and `entity_cache: EntityCache`.
> The Ambiguity Detector and Disambiguator remain **functions** taking an LLM, so their backends
> (`ad_llm`, `dis_llm`) are held directly. Field ordering uses `kw_only=True` (fixing the Pass-3
> non-default-after-default bug); `build()` passes everything by keyword.

---

## Implementation

```python
# pipeline/components.py
"""Dependency container for one pipeline condition. Built once; injected into the orchestrator."""
from __future__ import annotations

from dataclasses import dataclass
from typing import Optional

import neo4j
from CyVer import PropertiesValidator, SchemaValidator, SyntaxValidator

from pipeline.entity_lookup.cache import EntityCache
from pipeline.llm import BaseLLM
from pipeline.schema_linker.linker import SchemaLinker
from pipeline.query_generator.generator import QueryGenerator
from pipeline.types import SchemaRepr

# sentence_transformers.SentenceTransformer imported lazily/typing-only to keep import light.


@dataclass(kw_only=True)
class PipelineComponents:
    """All dependencies for one condition. Construct via build(); use as a context manager."""

    # Constructed stage objects (condition-specific)
    query_generator: QueryGenerator
    schema_linker: Optional[SchemaLinker] = None      # None for baseline (no SL)
    ad_llm:  Optional[BaseLLM] = None                  # None unless disambiguation_enhanced
    dis_llm: Optional[BaseLLM] = None                  # None unless disambiguation_enhanced

    # Shared graph resources
    neo4j_driver: neo4j.Driver
    database_name: Optional[str] = None                # None = server default ("neo4j")

    # CyVer validators (built once with the driver; reused across calls)
    syntax_validator: SyntaxValidator
    schema_validator: SchemaValidator
    properties_validator: PropertiesValidator

    # Entity cache (loaded once from the live graph; used only by disambiguation_enhanced)
    entity_cache: Optional[EntityCache] = None

    # Schema + options
    schema: SchemaRepr
    embedding_model: Optional["SentenceTransformer"] = None   # for the semantic evaluator fallback
    use_prefilter: bool = False

    @classmethod
    def build(
        cls,
        *,
        query_generator: QueryGenerator,
        schema_linker: Optional[SchemaLinker],
        ad_llm: Optional[BaseLLM],
        dis_llm: Optional[BaseLLM],
        neo4j_uri: str,
        neo4j_auth: tuple,
        schema: SchemaRepr,
        database_name: Optional[str] = None,
        embedding_model: Optional["SentenceTransformer"] = None,
        use_prefilter: bool = False,
        load_entity_cache: bool = True,
    ) -> "PipelineComponents":
        """Open the driver, build the three CyVer validators, optionally load the entity cache.

        Call once per condition. The driver is closed by close() / __exit__. load_entity_cache
        defaults True (the POLE graph is tiny); set False for baseline/schema_grounded if desired.
        """
        driver = neo4j.GraphDatabase.driver(neo4j_uri, auth=neo4j_auth)
        cache = EntityCache.load(driver, database_name) if load_entity_cache else None
        return cls(
            query_generator=query_generator,
            schema_linker=schema_linker,
            ad_llm=ad_llm,
            dis_llm=dis_llm,
            neo4j_driver=driver,
            database_name=database_name,
            syntax_validator=SyntaxValidator(driver),
            schema_validator=SchemaValidator(driver),
            properties_validator=PropertiesValidator(driver),
            entity_cache=cache,
            schema=schema,
            embedding_model=embedding_model,
            use_prefilter=use_prefilter,
        )

    def close(self) -> None:
        self.neo4j_driver.close()

    def __enter__(self) -> "PipelineComponents":
        return self

    def __exit__(self, *exc) -> None:
        self.close()
```

---

## Edge cases

- **Per-condition instances:** one `PipelineComponents` per condition (C2's `schema_linker` has
  `beam_k=1`, C3's has `beam_k=5` + the locked `diversity_penalty`). 5.3 constructs them; this
  module just holds and wires.
- **Baseline:** `schema_linker=None`, `ad_llm=None`, `dis_llm=None`; the orchestrator's baseline
  branch never touches them. `entity_cache` may be `None` (unused).
- **Validators built once:** constructing `SyntaxValidator` etc. per call would re-query multilabel
  metadata each time — they're built once here and reused (3.7 reads them off `components`).
- **Context manager:** always use `with PipelineComponents.build(...) as components:` (or call
  `close()`) so the driver is released — important when 5.4 builds three conditions in sequence.
- **`database_name=None`** means the server default; passed straight through to validators,
  executor, evaluator.

---

## Acceptance criteria

Now (no DB; monkeypatch `neo4j.GraphDatabase.driver`, CyVer constructors, and `EntityCache.load`):
1. `PipelineComponents` is `kw_only`; constructing it requires all non-default fields and rejects
   positional args.
2. `build(...)` with patched driver/validators/cache returns a populated container; the three
   validators are the patched instances; `entity_cache` is the patched cache when
   `load_entity_cache=True` and `None` when `False`.
3. `with ... as c: ...` then `__exit__` calls `driver.close()` exactly once.

Deferred (live Neo4j): `EntityCache.load` returns the expected node counts; CyVer validators
construct against the real graph.

---

## Handoff

`PipelineComponents` (with `build()` + context manager) is what 5.3 constructs per condition and
5.2 consumes. The orchestrator reads: `schema_linker.link`, `query_generator.generate`, `ad_llm`,
`dis_llm`, `entity_cache`, the three validators (via `cyver_validator`), `neo4j_driver`,
`database_name`, `schema`, `embedding_model`, `use_prefilter`.
