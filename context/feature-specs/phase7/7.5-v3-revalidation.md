# 7.5 — v3 Staged Revalidation (gated runbook)

**Artefacts:** versioned results under `results/*_v3*`; updated success-criteria
scorecard in `docs/` (extend `results-walkthrough.md` or a v3 sibling).
**Depends on:** 7.1–7.4 all `done`. **GPU + live v3 Neo4j** (workflow rule §7).
**Consumed by:** the dissertation. This step produces evidence, not code — any code it
needs already exists (2.2/2.3 sweep+probe, 3.4 probe harness, 5.4 harness), all now
version-aware via 7.3.

---

## Objective

Re-run the measurement chain on the v3 substrate **cheapest-first with explicit
go/no-go gates**, so a still-broken substrate is caught in minutes of GPU time, not
after a ~5h 360-query end-to-end run. Every gate's numbers are recorded in the tracker
row (and decisions-log if a gate forces rework upstream).

## Gates (run in order; do not skip forward past a failed gate)

**G0 — substrate green (CPU + Neo4j, minutes).**
`experiments/validate_benchmark.py` re-passes on the live v3 graph; full offline test
suite green under the `t2c` env.

**G1 — SL intrinsic coverage (GPU, ~minutes–1h). The linchpin.**
Regenerate cached beams (`results/beams_{model_key}_v3.jsonl`, k=5) over all 120 v3
questions with `sl_adapter_v3`; compute Cov@5 / EM@1 exactly as 3.1 did.
- **Proceed if Cov@5 ≥ 0.60.** Target remains ≥0.85 (success criterion #5).
- Below 0.60 → **stop**, iterate 7.4 (more data / epochs / template coverage), record
  the loop in decisions-log. Nothing downstream is worth running under 0.60.

**G2 — sweep + probe re-run (GPU, ~1–2h).**
2.2 diversity-penalty sweep on v3 (the Cov@5 ≥ 0.85 guardrail may now be meetable —
re-lock `diversity_penalty` in the per-model `decoding` block); 2.3 entropy probe on
v3. This directly tests the correlation hypothesis from the v2 post-mortem: **if beam
diversity is real, entropy AUC should move off the 0.59 floor** (criterion #6: > 0.62).
An AUC that stays flat *despite* healthy Cov@5 is itself a reportable finding
(secondary signal genuinely weak, not starved).

**G3 — AD probe (GPU + Neo4j, ~10 min).**
Re-run the 3.4-style stratified probe (9–12 v3 questions). Expect non-zero entropies
now (G1 + the 7.3 entity-seed check feed it). Run twice if budget allows: base-model
AD, and an instruct/API `ad`/`dis` spec (the documented swap point) — the pair
separates "signal was missing" from "detector model too weak" for the dissertation.

**G4 — full end-to-end (GPU + Neo4j, ~5h).**
`run_evaluation` with `dataset_version: v3`, `results_tag: v3`, 120×3 conditions →
`results/tables_{model_key}_v3.md` + `metrics_{model_key}_v3.json`. If G3's API-AD
variant was the better detector, run C3 with that `ad`/`dis` spec (config-only) and
say so in the artefact name/tag.

## Reporting

Re-score all 7 success criteria (project-overview §9) on v3 alongside the frozen v2

## Acceptance criteria

1. Each gate's headline numbers (G1 Cov@5/EM@1; G2 chosen penalty + AUC; G3 detection
   counts; G4 Tables 1–3) recorded in the tracker row with job IDs, following the
   established provenance style.
2. No gate skipped forward past a failure; any G1 iteration loop documented.
3. v2 artefacts in `results/` untouched; all v3 artefacts carry the `_v3` tag.
4. Success-criteria scorecard updated with v2 and v3 columns.

Phase 7 complete: the dissertation has a frozen v2 baseline, a validated v3 substrate,
and the same instrumented pipeline measured on both. Remaining optional work (6.1
