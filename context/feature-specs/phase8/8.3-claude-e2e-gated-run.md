## Objective

Run the whole measurement chain end-to-end on `claude-sonnet-4-6` (registry key
`claude-sonnet`), cheapest-first with go/no-go gates, so a format/environment problem
is caught for cents — as the reverted attempts' gating caught the parser mismatch in
~20 min — not after the multi-hour full run. This completes 5.5's deferred criterion 4
(API smoke + full API run) on the v3 substrate, and gives the dissertation its
"same pipeline, same substrate, stronger model" column next to v2-mistral and
v3-mistral.

**Method framing (locked, 5.5 / 2026-06-30):** C2/C3 are **stage-presence**, not SFT,
for an API model; SL distribution = temperature sampling with frequency weighting
(uniform −1.0 scores). **Evidence freezing:** sampling is nondeterministic, so the
cached sample files written by G1/G2 ARE the frozen evidence — every downstream
rescore is deterministic from the cache; a re-run regenerates rather than reproduces
(state this in the dissertation's method notes).

## Gates (run in order; do not skip forward past a failed gate)

**G0 — substrate green (free, minutes).** Full offline suite green under `t2c`
(includes 8.1's rescore guard); `experiments/validate_benchmark.py` re-passes on the
live v3 graph.

**G0.5 — raw-output smoke (`82_api_smoke_v3.slurm`; ~$0.10, minutes). NEW.**
Read the report by eye: (a) egress from the compute node works — if not, STOP and
rearchitect the run placement (login-node harness + `srun --overlap` Neo4j) before
spending anything; (b) raw SL completions vs parsed patterns — the 8.1 contract holds
(bare line, colons, no fences) or the misses are parser-covered; (c) AD/Dis JSON
parses; QG `_clean_cypher` yields executable Cypher; (d) record the `count_tokens`
prefix numbers (caching viability — optional wiring only if ≥2048).

**G1 — SL intrinsic coverage (`83_g1_coverage_api_v3.slurm`; ~600 calls, ≈$2,
~20 min).** Full 120 v3 questions, k=5 samples at pre-sweep temperature 0.7 (instruct
prompt), cached to `results/beams_claude-sonnet_v3.jsonl`; Cov@5/EM@1 computed exactly
as 7.5 G1.
- **Proceed if Cov@5 ≥ 0.60.** Target ≥ 0.85 (success criterion #5). Reference points:
  reverted attempt hit 0.583 with parser tolerance alone (no prompt variant);
  v3-mistral G1 was 0.683.
- Below 0.60 → **stop**, iterate the 8.1 few-shots/format contract (prompt-only loop,
  cheap), record in decisions-log.

**G2 — temperature sweep + entropy probe (`84_sweep_api_v3.slurm`; ~1800 calls, ≈$6,
~1h).** Sweep T ∈ {0.3, 0.7, 1.0} (no top_p per 8.2), lock
`decoding[claude-sonnet]` in `config/schema_linker_inference.yaml` (Cov@5 ≥ 0.85
guardrail, documented fallback if none qualifies — as 7.5 G2a); rescore the 2.3
entropy probe CPU-only from the model-keyed cache. Criterion #6 bar: AUC > 0.62
(v3-mistral: 0.689). Canonical-pattern entropy (8.1) is what makes this AUC honest
for a chatty model.

**G3 — AD/Dis probe (`80_ad_probe_v3.slurm` API variant; 10 questions, ≈$1,
~10 min).** Claude as AD (and SL, per the 8.2 generalisation) on the stratified v3
sample. This is the **API-AD leg 7.5 explicitly deferred** ("no API key") — the
base-7B-vs-API detector pair separates "signal missing" from "detector too weak" for
the dissertation. Expect recall well above base-7B's 4/10.

**G4 — full end-to-end (`86_run_evaluation_api_v3.slurm`; 120×3, est. 2–4h wall,
≈$30–60 at $3/$15 per MTok without caching).** `run_evaluation` →
`results/tables_claude-sonnet_v3.md` + `metrics_claude-sonnet_v3.json`. Watch the
first ~10 questions' log for API errors/backoff storms before walking away.
