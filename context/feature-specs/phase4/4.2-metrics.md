# 4.2 — Metrics & Tables

**Module:** `pipeline/evaluation/metrics.py`
**Depends on:** 0.1 (`EvaluationResult`, `Condition`), 4.1 (produces the `EvaluationResult`s)
**Consumed by:** 5.4 (the harness computes metrics per condition and prints the tables).

---

## Objective

Aggregate a list of `EvaluationResult`s (one condition, all 125 questions) into a `MetricBundle`,
and render Tables 1–3. `MetricBundle` and `compute_metrics` live here (not in `types.py`) — they're
a terminal aggregate, not a stage contract.

`(results, ad_predictions) → MetricBundle`

---

## `MetricBundle` + `compute_metrics`

```python
# pipeline/evaluation/metrics.py
"""Aggregate EvaluationResults into a MetricBundle; render the three result tables."""
from __future__ import annotations

from dataclasses import dataclass
from typing import Optional

from pipeline.types import Condition, EvaluationResult


@dataclass
class MetricBundle:
    # Table 1 — overall (all 125)
    ex: float                 # primary: Execution Accuracy vs default interpretation
    ea: float                 # secondary: relaxed AREA (matches any interpretation)
    kg_valid_pct: float       # % CyVer-accept (final state)
    syntax_pct: float
    schema_pct: float         # schema-pass GIVEN syntax-pass
    pass_at_1: float          # EX on the first attempt, before any retry loop
    # Table 2 — ambiguity-specific (50 ambiguous)
    ambiguous_ea: float
    dsr: float                # Condition 3 only; NaN otherwise
    detection_f1: float       # Condition 3 only; NaN otherwise
    detection_prec: float
    detection_rec: float
    per_type_ea: dict         # {"schema":…, "entity":…, "intent":…, "temporal":…}
    # Table 3 — repair/routing (C2, C3)
    initial_valid_pct: float
    post_cyver_valid_pct: float
    structural_repair_pct: float
    semantic_repair_pct: float   # C3 only
    avg_iterations: float


def compute_metrics(
    results: list[EvaluationResult],
    ad_predictions: Optional[list[tuple[str, bool]]] = None,   # [(question_id, AD_pred)] — C3 only
) -> MetricBundle:
    """All metrics from one condition's EvaluationResults.

    ad_predictions is required for dsr / detection_*; pass None for C1 and C2 (those become NaN).
    """
    n = len(results)
    ambiguous = [r for r in results if r.ambiguity_type is not None]
    first_attempt = [r for r in results if r.is_first_attempt]

    ex = sum(r.is_correct for r in results) / n
    ea = sum(r.matches_any_interpretation for r in results) / n
    kg_valid = sum(1 for r in results if r.cyver_result and r.cyver_result.route_to == "accept") / n
    syntax_pct = sum(1 for r in results if r.cyver_result and r.cyver_result.syntax_valid) / n
    syntax_passed = [r for r in results if r.cyver_result and r.cyver_result.syntax_valid]
    schema_pct = (sum(1 for r in syntax_passed if r.cyver_result.schema_score >= 1.0)
                  / len(syntax_passed)) if syntax_passed else 0.0
    pass_at_1 = (sum(r.is_correct for r in first_attempt) / len(first_attempt)) if first_attempt else 0.0

    ambiguous_ea = (sum(r.matches_any_interpretation for r in ambiguous) / len(ambiguous)) if ambiguous else 0.0
    per_type_ea = {}
    for t in ("schema", "entity", "intent", "temporal"):
        sub = [r for r in ambiguous if r.ambiguity_type == t]
        per_type_ea[t] = (sum(r.matches_any_interpretation for r in sub) / len(sub)) if sub else 0.0

    if ad_predictions is not None:
        flagged = {qid for qid, pred in ad_predictions if pred}
        fr = [r for r in results if r.question_id in flagged]
        dsr = (sum(r.is_correct for r in fr) / len(fr)) if fr else 0.0
        pred_map = dict(ad_predictions)
        gt_map = {r.question_id: (r.ambiguity_type is not None) for r in results}
        tp = sum(1 for q in pred_map if pred_map[q] and gt_map.get(q, False))
        fp = sum(1 for q in pred_map if pred_map[q] and not gt_map.get(q, False))
        fn = sum(1 for q in pred_map if not pred_map[q] and gt_map.get(q, False))
        prec = tp / (tp + fp) if (tp + fp) else 0.0
        rec = tp / (tp + fn) if (tp + fn) else 0.0
        f1 = 2 * prec * rec / (prec + rec) if (prec + rec) else 0.0
    else:
        dsr = prec = rec = f1 = float("nan")

    initial_valid = sum(1 for r in first_attempt if r.cyver_result and r.cyver_result.route_to == "accept")
    initial_valid_pct = (initial_valid / len(first_attempt)) if first_attempt else 0.0
    initial_invalid = [r for r in first_attempt
                       if not (r.cyver_result and r.cyver_result.route_to == "accept")]
    invalid_ids = {r.question_id for r in initial_invalid}
    repaired = [r for r in results if r.question_id in invalid_ids
                and r.cyver_result and r.cyver_result.route_to == "accept"]
    structural_repair_pct = (len(repaired) / len(initial_invalid)) if initial_invalid else 0.0

    first_wrong = [r for r in first_attempt if r.failure_mode == "wrong_result"]
    wrong_ids = {r.question_id for r in first_wrong}
    sem_repaired = [r for r in results if r.question_id in wrong_ids and r.is_correct and not r.is_first_attempt]
    semantic_repair_pct = (len(sem_repaired) / len(first_wrong)) if first_wrong else 0.0

    avg_iterations = (sum(r.retry_count for r in results) / n) if n else 0.0

    return MetricBundle(
        ex=ex, ea=ea, kg_valid_pct=kg_valid, syntax_pct=syntax_pct, schema_pct=schema_pct,
        pass_at_1=pass_at_1, ambiguous_ea=ambiguous_ea, dsr=dsr,
        detection_f1=f1, detection_prec=prec, detection_rec=rec, per_type_ea=per_type_ea,
        initial_valid_pct=initial_valid_pct, post_cyver_valid_pct=kg_valid,
        structural_repair_pct=structural_repair_pct, semantic_repair_pct=semantic_repair_pct,
        avg_iterations=avg_iterations,
    )
```

---

## Tables

`format_metric_tables(bundles: dict[Condition, MetricBundle]) -> str` returns the three markdown
tables. `dsr`, `detection_*`, `semantic_repair_pct` render as `—` when `NaN` (C1/C2).

- **Table 1 — Overall (125):** rows EX, EA/AREA, KG-Valid %, Syntax %, Schema %, Pass@1 ×
  {C1, C2, C3}. (Pass@1→EX gap = repair uplift.)
- **Table 2 — Ambiguity-specific (50):** Ambiguous EA, DSR, Detection F1/Prec/Rec, and per-type EA
  (schema n=13, entity n=11, intent n=11, temporal n=15). DSR + Detection are C3 only.
- **Table 3 — Repair/routing (C2, C3):** Initial Valid %, Post-CyVer Valid %, Structural Repair %,
  Semantic Repair % (C3 only), Avg Iterations.

These three tables are the empirical core of the thesis: Table 1 monotonic C1≤C2≤C3, Table 2 the
ambiguity-subset gains and detection quality, Table 3 the repair-loop contribution.

---

## Edge cases

- **NaN propagation:** C1/C2 pass `ad_predictions=None` → DSR/Detection are `NaN` → render `—`.
- **`post_cyver_valid_pct == kg_valid`** by construction (both are the final-state accept rate).
- **Detection F1 keys on the binary** `ambiguity_type is not None`, never on type-set equality — so
  the AD emitting multi-type predictions doesn't affect it.
- **Empty subsets** (e.g. no ambiguous results) → 0.0, never division by zero (guards throughout).
- `avg_iterations` uses `retry_count`, which the orchestrator records as the total retries for the
  finally-recorded attempt of each question.

---

## Acceptance criteria (all runnable now — pure aggregation, no GPU/DB)

1. On a hand-built list (a few correct, one `valid_non_default`, one `invalid_query`), `ex`, `ea`,
   `kg_valid_pct` match hand-computed values.
2. `per_type_ea` partitions the ambiguous subset correctly; an absent type → 0.0.
3. With `ad_predictions`, `detection_prec/rec/f1` match a hand-computed confusion matrix; with
   `None`, all four detection/DSR fields are `NaN`.
4. `pass_at_1` uses only `is_first_attempt` rows; `structural_repair_pct` counts questions invalid
   on first attempt but accepted finally; `semantic_repair_pct` counts first-attempt `wrong_result`
   that became correct on a later (non-first) attempt.
5. `format_metric_tables({...})` renders three markdown tables with `—` in C1/C2 DSR/Detection cells.

## Handoff

`compute_metrics(results, ad_predictions) → MetricBundle` and `format_metric_tables(bundles)`. 5.4
runs every condition, collects each condition's `EvaluationResult`s (and C3's `ad_predictions` from
the `PipelineState`s), calls `compute_metrics` per condition, and prints the tables.
